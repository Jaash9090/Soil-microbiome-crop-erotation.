Microbiome Crop Predictor — Scientific Validation

STAGED BETA / EXTERNAL AUDIT MODE
Microbiome-based crop yield inference is not activated. No verified paired microbial, soil, and crop-outcome dataset or independent validation results have been provided. No synthetic crop-outcome metrics are generated.

Required paired evidence

1. Microbial profile

16S/ITS ASV/OTU counts or abundance matrix with sample IDs

2. Soil chemistry

Matched soil pH, carbon, EC, nutrients and relevant field metadata

3. Crop outcome

Matched observed yield, biomass, or disease incidence with field identifiers

Local dataset schema validator

Choose a CSV containing paired observations. Files are processed in your browser and not uploaded. This checks column structure and values, not scientific validity.

Required columns: sample_id, otu_id, abundance, soil_ph, crop, yield_kg_ha, field_id, region. Multiple OTU rows per sample are supported; yield and soil metadata should be repeated consistently within a sample.

Validation workflow

Public/field sample accessions → verified paired sample metadata → DADA2/ASV processing and SILVA/UNITE annotation → cross-field/region holdout → independent audit → conditional production release.

Public repositories to examine: NCBI SRA, MG-RAST, Qiita.
